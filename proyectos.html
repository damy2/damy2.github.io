Mis Proyectos Destacados

Comedero Automático de Perros

Este proyecto personal consistió en el diseño y la implementación de un comedero automático para perros. Para su desarrollo, utilicé una placa Arduino, lo que me permitió controlar la dispensación de alimento de forma programada. La construcción física del comedero se llevó a cabo utilizando piezas impresas en 3D, lo que demostró mi capacidad para combinar habilidades de programación, electrónica básica y diseño CAD (Diseño Asistido por Computadora) para crear una solución integral y funcional. Este proyecto me enseñó la importancia de la integración hardware-software y la aplicación de la tecnología para resolver problemas cotidianos.

Aplicación Móvil para Médicos

Desarrollé una aplicación móvil sencilla diseñada para facilitar ciertas tareas a los profesionales médicos. Este proyecto se dividió en dos componentes principales: el frontend y el backend. El frontend, la parte visible e interactiva para el usuario, fue construido utilizando Kotlin, un lenguaje moderno y conciso para el desarrollo de aplicaciones Android. El backend, que gestiona la lógica del negocio y la base de datos, se implementó con Spring Boot y Java. Esta elección tecnológica me permitió trabajar con un framework robusto y ampliamente utilizado en la industria para el desarrollo de APIs y servicios web. Este proyecto me brindó experiencia valiosa en el ciclo completo de desarrollo de una aplicación, desde la interfaz de usuario hasta la gestión de datos en el servidor.
